Confidentialité

Votre bibliothèque reste chez vous.

Ce que Relay stocke, ce qu’il contacte, et comment tout effacer. Sans jargon.

Local d’abord

Votre bibliothèque et vos préférences sont stockées sur votre ordinateur, pas sur un serveur.

Aucun compte

Relay ne vous demande ni inscription ni connexion pour fonctionner.

Aucun suivi

L’application n’embarque aucun outil de statistiques d’usage ni de publicité.

Ce qui reste sur votre PC

DonnéeEmplacement
Bibliothèque et préférences%APPDATA%\nexora\relay.sqlite
Images en cache%APPDATA%\nexora\artwork (par défaut, modifiable)
Clés API facultativesChiffrées avec le stockage sécurisé de Windows

Relay n’envoie pas votre liste de jeux à un service en ligne.

Ce que Relay contacte

Pour fonctionner, l’application interroge des services publics. Comme avec n’importe quel site web, ils voient l’adresse IP de la connexion.

ServicePourquoiCe qui est demandé
GitHubVérifier les nouvelles versions (installation standard)La dernière version publiée
SteamImages et descriptions des jeux SteamL’identifiant du jeu
egdataImages et descriptions des jeux Epic GamesLe titre ou l’identifiant du jeu
Riot GamesVisuels officiels des jeux RiotLe visuel du jeu
SteamGridDB, IGDBCompléter les images et descriptions manquantesLe nom du jeu, uniquement si vous renseignez vos clés

Clés API facultatives

Certaines fonctions (import des jeux possédés sur Steam, sources d’images supplémentaires) demandent vos propres clés. Elles sont chiffrées sur votre PC et envoyées uniquement au service concerné.

Ce site

Ce site n’utilise ni cookies, ni outil de statistiques. Pour afficher les jaquettes, votre navigateur les charge depuis les serveurs de Steam, et la page d’accueil interroge l’API de GitHub pour trouver le lien de téléchargement : ces services voient donc votre adresse IP. L’hébergeur du site peut aussi conserver des journaux techniques classiques.

Vos choix

  • Effacer vos données : fermez Relay puis supprimez le dossier %APPDATA%\nexora. Désinstaller Relay ne le supprime pas.
  • Limiter les échanges : ne renseignez pas de clés API, et utilisez la version portable si vous ne souhaitez pas de mises à jour automatiques.
