Questions fréquentes

Avant de vous lancer.

Quelles plateformes sont prises en charge ?

Nexora détecte les jeux installés depuis Steam, Epic Games et Riot Games, et permet aussi d’ajouter des jeux locaux. La prise en charge varie selon la plateforme.

Dois-je connecter mes comptes ?

Non pour détecter les jeux installés. Certaines fonctions facultatives, comme l’import de jeux possédés sur Steam ou la recherche de métadonnées, nécessitent vos propres identifiants API.

Windows affiche un avertissement lors de l’installation ?

Nexora n’étant pas signée, Windows peut indiquer que l’éditeur est inconnu. Téléchargez toujours l’application depuis les releases officielles de ce dépôt GitHub.

Comment les mises à jour de Nexora sont-elles distribuées ?

Les nouvelles versions seront publiées dans les releases GitHub. Les installations standard de Nexora pourront ensuite les détecter automatiquement.
