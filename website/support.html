Dépannage

Problèmes courants.

Un de mes jeux n’apparaît pas

Vérifiez que le jeu est bien installé et que son launcher (Steam, Epic Games ou Riot) est installé sur ce PC, puis cliquez sur « Synchroniser ». Si le jeu vient d’une autre plateforme ou d’un dossier personnalisé, ajoutez-le comme jeu local en glissant son .exe dans la fenêtre. Xbox, Ubisoft Connect, EA app, GOG Galaxy et Battle.net ne sont pas encore pris en charge.

L’image ou la description d’un jeu est fausse

Ouvrez la fiche du jeu et utilisez « Corriger la correspondance » pour choisir le bon jeu, ou « Ma jaquette » et « Ma bannière » pour imposer vos propres images. « Actualiser » relance la récupération.

Windows affiche un avertissement à l’installation

Relay n’est pas encore signé : Windows SmartScreen peut indiquer que l’éditeur est inconnu. Cliquez sur « Informations complémentaires » puis « Exécuter quand même », après avoir téléchargé le fichier depuis la page de téléchargement ou les releases officielles.

Le jeu ne se lance pas

Relay transmet le lancement au launcher du jeu. Vérifiez que ce launcher est ouvert et connecté, que le jeu s’y lance bien directement, puis réessayez. Pour un jeu local, vérifiez que le chemin du .exe n’a pas changé.

Les mises à jour automatiques ne fonctionnent pas

Elles ne concernent que l’installation standard : la version portable doit être remplacée à la main. Vérifiez aussi votre connexion, puis comparez votre version avec la dernière sur la page Changelog. Vous pouvez toujours réinstaller la dernière version par-dessus l’ancienne.

Où sont stockées mes données, et comment tout réinitialiser ?

Dans %APPDATA%\nexora (base relay.sqlite et images en cache). Fermez Relay puis supprimez ce dossier pour repartir de zéro. Désinstaller Relay ne le supprime pas. Les détails sont dans la documentation.

Écrire un bon signalement

Plus votre message est précis, plus vite le problème sera résolu.

À inclure

  • La version de Relay (visible dans le nom du fichier installé ou sur la page des releases).
  • Votre version de Windows (10 ou 11).
  • Le jeu et la plateforme concernés.
  • Les étapes pour reproduire le problème, et ce que vous attendiez.
  • Une capture d’écran, si elle aide.

À ne jamais partager

  • Vos clés API (Steam, SteamGridDB, IGDB…).
  • Le contenu de votre dossier de données ou de la base relay.sqlite.
  • Des mots de passe ou identifiants de compte.
